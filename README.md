# My Princess — Interactive Birthday Website

A responsive, animated birthday experience.

## Personalize it
1. Replace `assets/photos/photo-1.jpg` through `photo-10.jpg` with her photos. Keep the filenames.
2. Add an MP3 you have permission to use as `assets/birthday.mp3`.
3. Open `index.html` in a browser to test.

The soundtrack starts when she clicks **The birthday of someone special** and loops until the page is closed. Browser playback is permitted because it follows her click.

## Publish on GitHub Pages
1. Create a GitHub repository and upload all files/folders from this ZIP.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to show the public website URL.

## Wish form
The wish field currently confirms the wish on screen and saves it in that browser's local storage. It does not email the wish. Email delivery requires connecting an email service such as EmailJS and adding its configuration.

The website includes placeholder paths for ten photos and the music file; add your own assets before publishing.
